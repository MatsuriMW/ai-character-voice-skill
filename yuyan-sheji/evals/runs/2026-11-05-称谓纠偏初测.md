# 称谓纠偏初测（2026-11-05）

用例 15b，自己按 `references/称谓纠偏.md` 走了 `examples/19` 那几段。**这是作者自测，没有独立的人或模型跑过，也没有测过冷启动时 skill 会不会被触发。**

| 项 | 结果 |
|---|---|
| 明确的错（奴才、家父、内外、Sir Smith、Your Honour） | 都能给依据和等级 |
| 方向反（家父、内外） | 判为错 |
| 跳变（老爷、大人） | 判为跳变 |
| 写对的（大人、钱太爷） | 不误改 |
| 信源打架（晚清知县） | 停下来问，列出四条信源和等级 |
| 脚本 | `era --period qing` 查不了称谓方向，例如「奴才叩见大人」不报，要靠人工 |

写这份用例时发现的：

- 之前写进明代表的「老父母」，《儒林外史》第三回里其实没有，只有「县父母」。按这个模式的信源规则核了一遍才查出来，已改。
- 「钱太爷」原文确认是典史，支持「太爷给小官」这一说，也让知县的称呼更拿不准。
- 用户看过信源后定了知县的口径（日常太爷，公堂大老爷），和推荐不同，照用。
- 回原文核说话人时发现：「老哥、兄弟」是巡抚对道台、道台对巡捕，示例里写成巡抚对知县是依据用过头了，已改。**引小说时要核谁对谁说。**
- 用户指出称呼一定要先看上对下、下对上还是平辈。原来的流程把它混在「方向」里，上面那个错就是这么来的。已改成每处必填，并要求 A 叫 B、B 叫 A 配对查。
