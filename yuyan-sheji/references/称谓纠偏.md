# 称谓纠偏（模式 A）

谁叫谁、自称什么，是观众最容易听出错的地方。这个模式只查这一件事：**中日英、古今都能用，不用建档，给一句台词也能做**。

**第一件事永远是定上下：这句话是上对下、下对上，还是平辈（第二节）。**

它不重新讲称谓知识，只管流程：怎么抽、怎么判、查哪里、拿不准怎么办。知识在路由表指向的文件里。

---

## 一、底线：拿不准就问用户

**称谓是事实问题，也是创作决定。模型最常犯的错不是不知道，是不知道却写得很肯定。** 所以这个模式宁可停下来问，也不猜。

### 什么算拿不准（有一条就算）

1. **信源打架**：两个来源说法不一样。
2. **没有信源**：只有模型自己的记忆，或者只有「大家都这么说」。
3. **信源对不上**：资料说的是别的年份、地区、阶层。
4. **这个 skill 里标了〔待核〕**，或者根本没写。
5. **规范和实际用法不一样**：语文书说不对，可是大家都这么说（如「我夫人」）。
6. **影视叫法和史实冲突，这部戏又没定层**（皇阿玛、师座）。这其实是创作决定，该用户拍板。
7. **关系没交代**：剧本没说谁上谁下、是不是平辈、是不是一家人；或者职位和辈分打架，又没说这场按哪个算。
8. **方言和外语**：地方叫法、没有母语者核过的日语和英语细节，又刚好是关键台词。
9. **真实的人、机构、现行职务**：称呼可能有官方规定，也可能变过。

### 不许这样

- 拿不准还给一个肯定的答案，或者默默换成「通行说法」。
- 把模型记忆写成信源，或者编出处。**查不到就说查不到。**
- 把「拿不准」判成「错」，改掉用户本来可能写对的称呼。
- 只问「这样对吗？」，让用户自己去查。

### 能查先查

有联网工具就先查，查完还拿不准再问。问的时候说清查了什么、没查到什么。没有联网工具就直说没查，信源栏只写这个 skill 里有的。

### 怎么问

**一次问一处**，同一类的合并成一问（全剧的知县都这么叫，只问一次）。有 AskUserQuestion 这类工具就用，问题里要带原句，让用户不看上文也能决定。

```
第 3 处：「相公请留步」（仆人对秀才，明代）

为什么拿不准：几个来源说的不是同一回事，当面到底叫什么，我判断不了。

信源：
- A 说法：……（来源，一手 / 工具书 / 二手；读了原文还是只看到转引）
- B 说法：……（来源，等级）
- 查过没查到：……

选项：
1. 用 X（后果：……）
2. 用 Y（后果：……）
3. 保留原文（后果：……）

我推荐 1，因为……。这是判断，不是事实。
```

### 信源等级（照实写）

| 等级 | 例子 |
|---|---|
| **一手** | 当时的原著、公文、法令、日记；官方机构现行的规定（如法院官网） |
| **工具书、研究** | 《称谓录》、OED、《敬語の指針》、论文；写明读了原文还是只看到摘要 |
| **二手** | 考证文章、读书摘录、百科、礼仪网站；多家一致也还是二手 |
| **影视、小说** | 只能证明「观众听过」；小说写前朝时不能证明前朝 |
| **模型记忆、常识** | **不算信源**，可以说「我记得」，要明确说没有来源 |

### 用户决定以后

- 写进**称谓决定表**（`templates/称谓纠偏报告.md`），全剧生效，不再问第二遍。来源标〔用户定〕，写一句理由。
- **用户的决定优先于资料**。和资料不同也照做，这是创作决定，不算错；只记一笔和哪个说法不同。
- 用户说「你定」：按推荐定，标〔你定·推测〕，列在报告最后，方便他回头改。
- 用户还没回的：**保留原文**，标「待决定」，不替他换。

## 二、先定上下：每处称谓必填

**同一个人，对上、对平辈、对下，是三套称呼。** 不先定上下，后面全是猜。

每处称谓先填三选一：`下对上`、`平辈`、`上对下`。填不出来，就是关系没交代，算拿不准（第一节第 7 条）。

### 上下怎么算

上下由这两个人所在的秩序定，不只看年龄：

| 秩序 | 谁在上 | 例 |
|---|---|---|
| 官职、职位 | 职位高的 | 巡抚对知县；部长对课长 |
| 辈分 | 长辈 | 叔叔对侄子；岳父对女婿 |
| 师承、资历 | 老师、先进门的 | 座师对门生；先輩对後輩 |
| 主仆、雇佣 | 主人、东家 | 老爷对丫鬟 |
| 买卖、服务 | 客人 | 店家对客官；公司对客户 |
| 年龄 | 年长的 | 其他秩序都不起作用时才看它 |

**几条秩序打架最有戏**：年长的下属、年轻的上司、门生做了大官、叔叔给侄子打工、中举的女婿和杀猪的岳父。通常公事按职位、私下按辈分（常识，没有来源）；剧本没写清的，算拿不准，问用户。

**上下变了，称呼要跟着变**：范进中举后，岳父胡屠户从骂他变成叫「贤婿老爷」。

### 每处要查四件事

1. **自称和对称同向**：下对上要自谦、抬对方。「在下」配「小子」不通，除非他是故意的。
2. **两头要配对**：A 怎么叫 B，也要查 B 怎么叫 A。卑职和大人是一对，贵县和本院是一对。
3. **有没有用反**：对上用了对下的词（下属叫上司贤弟），或者上级说了下级的词（上司自称卑职）。
4. **例子不能搬**：资料里的例子是谁对谁，要核。巡抚对道台说「老兄」，不等于巡抚对知县也这么说。

**上对下也可以客气**，这常常是戏：《官场现形记》里降调的道台对巡捕自称兄弟，叫他老哥。写的时候要知道这是在反着用。

### 上下定了，再定亲疏、场合、在场的人

同一对人不只有一个叫法。**称谓决定表要写到这一层**，不是一对人一个词。

| 再定 | 为什么 | 例 |
|---|---|---|
| **亲疏** | 上下和亲疏是两回事：熟的上司、不熟的同事 | 下属对老板：王总（疏）、王哥（私下熟了） |
| **场合** | 公事和私下不一样 | 百姓对知县：公堂大老爷，日常太爷；部下对部長：会议部長，酒局也可能名字さん |
| **在场的人** | 有更高的人、外人、孩子在场，要改 | 对客户说自家部長（`ja/02`）；夫妻当着孩子互称「你爸」「你妈」 |

一张六格表就够把一对人写清（现代中文公司的例子）：

| | 疏，或者公事 | 亲，或者私下 |
|---|---|---|
| 下对上 | 王总、您 | 王哥、王姐、老大 |
| 平辈 | 王经理、王老师、你 | 老王、名字、外号 |
| 上对下 | 小王、全名（开会点名、发火） | 小王、名字 |

### 说到第三人：三个人的上下

称呼不在场的人时，要同时看三个人：说话的、听话的、被说到的。

| 情况 | 规矩 | 例 |
|---|---|---|
| 说到对方家的人 | 敬 | 令尊；お父様 |
| 对外说到自家人 | 谦，哪怕他比你高 | 家父；日语「部長の田中」「父」 |
| 在更高的人面前说到比他低的人 | 不抬 | 日语对部長说課長，《敬語の指針》两种都承认（`ja/02`）。中文古代有「君前臣名，父前子名」的说法（我记得出自《礼记·曲礼》，**这次没核到原文，算〔待核〕**）；古装剧里皇上面前互称某大人，观众不觉得错，考据层要问用户 |
| **当面和背后** | 背后往往降一档，这就是人物 | 当面王总，背后老王；当面大人，背后那厮 |

- **当面的词和背后的词不能混**：下属当面叫「老王」是错或是戏，背后叫就很正常。
- 背后的叫法被本人听到，是现成的一场戏。

### 是错，还是故意反着用

上下用反不一定错。先问三件事：

1. 这场有事件让他这么叫吗？
2. 对方或旁人有反应吗？（没人反应的「羞辱」，多半是写错了）
3. 这个人知道规矩吗？

都没有，判 `错`。有，判 `戏`，保留并写进例外。看不出来，算拿不准，问用户。

| 反着用 | 方向 | 例 |
|---|---|---|
| **笼络** | 上对下抬高 | 降调的道台对巡捕叫老哥（《官场现形记》）；老板叫员工王哥 |
| **讽刺** | 把平辈、下级抬上去 | 「王大人日理万机」；「您老」；*Your Highness*（挖苦） |
| **羞辱** | 把人压下去 | 当众叫上司全名；对长辈说「你」；てめえ |
| **决裂** | 下对上丢掉敬称 | 从大人到你；从爹到老东西；从 *sir* 到叫名字 |
| **亲近** | 下对上放松 | 老部下私下叫王哥；对象之间互相叫大人（调情） |
| **不懂规矩** | 乱用 | 乡下人把官叫错；暴发户用力过猛（`principles.md`） |
| **露馅** | 装的身份撑不住 | 假扮官家小姐的丫鬟，一急就叫「小姐」 |

**关系的转折点，就是改口的地方。** 写一条时间线：哪一场、谁先改的口、对方接不接。对方不接（你叫我王哥，我还叫你小李）本身就是上下。

### 三个方向的骨架

只是骨架，细节按第四节去查。

| 场景 | 下对上 | 平辈 | 上对下 |
|---|---|---|---|
| 帝王 | 臣 / 陛下、皇上 | | 朕 / 卿、爱卿 |
| 古代官场 | 下官、卑职 / 大人 | 某兄、年兄（同科） | 本官、本府 / 尔等 |
| 晚清知县这一层 | 对知府：卑职 / 大老爷 | 老兄、仁兄、县尊 | 知府对他：贵县；他对百姓：本县 |
| 古代士人 | 晚生、学生 / 老先生、先生 | 在下、小弟 / 兄台、仁兄 | 愚兄 / 贤弟（年长对年少） |
| 古代主仆 | 奴婢、小的 / 老爷、小姐 | | 我 / 叫名字 |
| 古代平民对官 | 小人、草民 / 老爷、大人 | 我、俺 / 大哥、老哥 | 本官 / 你、这厮 |
| 民国军政 | 职 / 钧座、委座 | 字 + 兄 | 字 + 兄（资深对资浅，反过来不行） |
| 现代中文职场 | 我 / 王总、您 | 我 / 老张、你 | 我 / 小王 |
| 现代中文家庭 | 我 / 爸、叔、您 | 叫名字、哥、姐 | 我 / 叫名字、小名 |
| 日语职场（再看内外） | 私 / 部長、名字さん | 俺、僕 / 名字、名字さん | 俺、私 / 名字くん、名字さん |
| 英文军队、法庭 | *sir*、*my lord* | 叫名字 | 叫姓、军衔 |
| 英文摄政时期主仆 | *sir*、*ma'am*、*m'lord* | | 女仆叫名，男仆、管家叫姓 |
| 英文现代职场 | **常常都叫名字**，上下靠语气和用词体现 | 叫名字 | 叫名字 |

英文现代这一行要留意：**称呼不分上下，不等于关系没有上下**。别照中文硬加 *Boss Wang*。

## 三、流程

1. **收料**。台词；语言、时代（朝代或年份）、地点；古代戏的层（`era/00-时代轴.md`）。缺的一次问完，能从剧本读出来的不问。
2. **抽称谓**。逐处列出来，不只抓名词：
   - 自称（我、在下、卑职、俺、僕、I）
   - 对称（您和你的切换、大人、あなた、Sir）
   - 他称（说到不在场的人）
   - 称呼语（王总、亲、mate、ma'am）
   - 说到家里人和对方家里人（家父、令尊、母、お母様）
   - 日语还要看**该省没省**（`ja/00`）
3. **写清谁对谁，标上下**：谁说 → 对谁说（下对上、平辈、上对下）→ 说到谁 → 谁在场。谁在场常常决定一切：当着客户说老板，当着皇上说太监。
4. **机器先扫**。上下跑 `address`：`python3 scripts/yuyan_tool.py address 台词.md --lang zh --order "巡抚>知县=县丞>差役"`（高到低，同级用 `=`），能抓上级说了下级的词、下级说了上级的词、同一对人叫法跳变。古代再跑 `era`（明、清、民国加 `--period`），日语 `ja`，英文 `variety`。脚本只抓词表里有的，**听话人是按「回上一个人」猜的，也分不清当面和说到第三人，报出来的都要人工看**。
5. **逐处五问**，按第四节查：
   - **上下**：第二节的四件事过了吗？
   - **身份**：这个人配得上这个称呼吗？这个词是给这种人的吗？
   - **谦敬和内外**：有没有反？该抬谁、该压谁？听话的人是外人吗？
   - **时代和地域**：这个年份、这个地方这么叫吗？
   - **一致**：同一对关系前后一样吗？变了，有事件支撑吗？
6. **下结论**，每处一个：

   | 结论 | 意思 | 做什么 |
   |---|---|---|
   | `对` | 有依据，对 | 不动 |
   | `错` | 有依据，错 | 给依据和改法 |
   | `看层` | 影视叫法或规范有争议 | 这部戏定了层就按层；没定就算拿不准 |
   | `跳变` | 同一对关系没理由地换了叫法 | 统一，或者写成情节点 |
   | `戏` | 上下故意反着用，有事件支撑（第二节） | 保留，写进例外 |
   | `拿不准` | 第一节的任何一条 | **问用户** |

7. **先问，再定稿**。错的直接给改法；拿不准的按第一节问，问完才出定稿。
8. **只改称谓**。不顺手润色，不加戏。称谓一改，有些地方必须跟着改（日语的敬语和动词、对方的回话、字幕），单列成「连带改动」。
9. **连起来读一遍**：改口的地方接得上吗？对方的回应还对吗？
10. **交付**：`templates/称谓纠偏报告.md`。全剧的称谓决定表放在项目里，后面写台词都按它。

### 改口是戏，不一定是错

称呼变了，往往就是关系变了：范进中举，邻居当场从「范相公」改成「范老爷」；日本人从姓加さん到只叫名；英国人从 *Mr. Darcy* 到叫名字。

判断标准：**这次改口有没有事件支撑**。有，就保留并写进决定表的「例外」；没有，才是 `跳变`。

## 五、现代常见错

括号里是信源等级。没把握的不在这里，算拿不准。

### 三个方向速查（现代）

常识整理，**没有来源**，写具体行业和地区时再核。日语看 `ja/04`。

| 中文 | 下对上 | 平辈 | 上对下 |
|---|---|---|---|
| 公司 | 王总、王姐、您 | 老张、小李、名字 | 小王、名字；发火叫全名 |
| 体制内 | 王局、王处、领导、您 | 老张、小李；开会时同志 | 小王、名字；开会时同志 |
| 学校 | 王老师、您 | 名字、外号 | 全名、名字 |
| 家庭 | 爸、叔、您（北方多） | 哥、姐、名字 | 小名、名字；发火叫全名 |
| 买卖（客人算上） | 店家对客人：您、哥、姐、亲 | | 客人对店家：老板、师傅、服务员 |

| 英文 | 下对上 | 平辈 | 上对下 |
|---|---|---|---|
| 美国公司 | **多半叫名字**；初见或很正式才 *Mr. / Ms.* | 名字 | 名字 |
| 学校 | 美国 *Mr. / Ms. Smith*；英国 *Sir*、*Miss* | 名字 | 名字 |
| 军队 | *sir*、*ma'am*；对军士叫 *Sergeant* | 名字、姓 | 军衔 + 姓、姓 |
| 家庭 | *Mom*、*Dad*、*Uncle Joe* | 名字 | 名字、昵称；发火叫全名 |
| 美国南方 | 对长辈多用 *sir*、*ma'am* | | |

| 日语 | 下对上 | 平辈 | 上对下 |
|---|---|---|---|
| 公司 | 部長、名字さん | 名字、名字さん | 名字くん、名字さん（`ja/04`） |
| 学校 | 先輩、名字先輩 | 名字、あだ名 | 名字くん、名字ちゃん、直接叫名字 |
| 家庭 | お父さん、お兄ちゃん（**不叫名字**） | | 叫名字（`ja/01` 第 3 条） |

### 中文

| 错 | 对 | 依据 |
|---|---|---|
| 问别人：「家父身体可好？」 | 令尊。家父只说自己的父亲 | 语文差错辨析类文章，多家一致（二手） |
| 「您令尊」「你的令尊」 | 令尊。「令」已经是敬称，不再加人称 | 同上（二手） |
| 说自己的父亲：「我令尊」 | 家父、我父亲、我爸 | 同上（二手） |

**现代泛称没有唯一正确答案**，看地区、年代、行业、年龄。下面是要问的，不是答案：

| 称呼 | 要看什么 |
|---|---|
| 小姐 | 在大陆一些地方、一些年代有歧义，也有地方照常用；海外华人、台湾、正式场合通常没问题 |
| 同志 | 体制内是正常称呼；日常另有同性恋的意思 |
| 师傅 | 工人、司机、手艺人；北方泛称更多 |
| 老师 | 已经泛化到文艺、媒体、知识行业 |
| 美女、帅哥、亲、宝 | 服务和带货场景；看年代（〔待核〕年份） |
| 王总、老板、领导 | 公司用总和老板，体制内用领导和职务；小公司人人都是总 |
| 姥姥、外婆 | 大致北方姥姥、南方外婆，但河南等地两种都有，湖北有「家家」（二手）；**写具体地方要核** |
| 老公、爱人、媳妇、对象 | 看年龄、地区；「我夫人」规范上有争议，实际上很多人这么说（算拿不准第 5 条） |

这方面有专门研究（刘永厚《汉语社会称谓语的语义演变》等），这里**只看到了简介，没读**。关键台词要问用户，或者让他问当地人。

### 英文

| 错 | 对 | 依据 |
|---|---|---|
| *Sir Smith* | *Sir John Smith*，当面 *Sir John*；*Dame Maggie* 同理 | Debrett's（一手）；baronet 协会 |
| 爵士的妻子叫 *Lady Jane* | *Lady Smith*。只有公爵、侯爵、伯爵的女儿才叫 *Lady Jane* | Debrett's（一手） |
| 伯爵的女儿嫁给平民后叫 *Lady Berkeley* | *Lady Charlotte Berkeley*，当面 *Lady Charlotte* | Debrett's（一手） |
| *Good morning, earl* | *Lord Debrett*。公爵以下都称 Lord / Lady；公爵当面才叫 *Duke* | Debrett's（一手） |
| *Baroness Margaret Thatcher* | *Baroness Thatcher*（头衔加姓） | Debrett's（一手） |
| *Mr. John*（一般情况） | *Mr. Smith*：Mr、Mrs、Ms 接姓 | 英语用法书、Cambridge Grammar（只看到摘要） |
| 英国法庭一律 *Your Honour* | 治安法官 *Your Worship* 或 *Sir / Madam*；地区法官、审裁处 *Judge*；巡回法官 *Your Honour*；高等法院及以上 *My Lord / My Lady* | 律师监管局 SRA、英国司法机构官网（一手），英格兰和威尔士 |
| 美国法庭说 *My Lord* | *Your Honor* | 常识，无来源；写实的美国法庭戏再核 |

*Mr. John*、*Miss Sarah* **不一定错**：美国南方有这种敬老或亲切的叫法（二手，语法网站）。写南方角色时算对，写别的地方算错，拿不准就问。

### 日语

规则都在 `ja/` 里，这里只列最常被问的。

| 错 | 对 | 依据 |
|---|---|---|
| 对客户说「田中部長がいらっしゃいません」 | 「部長の田中は席を外しております」 | 《敬語の指針》和 `ja/02` |
| 宛名、当面「部長様」「社長様」 | 「田中部長」「部長の田中様」。职务本身就是敬称，再加様算二重 | 商务礼仪网站，多家一致（二手）；**没查到《敬語の指針》的明文** |
| 对上级说あなた | 职务、さん，或者省略 | 鈴木孝夫的规律（`ja/01`） |
| 成年人对外说「うちのお父さんが」 | 父が | `ja/01`；学生和年轻人也有这么说的，看人设 |

**公司内部叫「部長さん」行不行**：各公司不一样，也有公司规定全员叫さん。没有统一答案，算拿不准第 7 条，问用户这家公司什么风气。

**日语这部分没有母语者听过**，关键场次要告诉用户。

## 六、跨语言

称谓最不能逐词翻。**先在目标语言里定这个人怎么叫，再写台词**（`语言模式.md` 的「双语和翻译」）。下面都是翻译腔，来自常识和翻译经验，没有查到系统研究；短剧行业文章也反复提到「全剧称谓要统一」（二手）。

| 中文 | 翻译腔 | 英文里通常怎么办 |
|---|---|---|
| 李老师 | *Teacher Li* | *Mr. Li*、*Ms. Li*；大学里 *Professor Li* |
| 王总 | *President Wang*、*CEO Wang* | *Mr. Wang*；熟了叫名字 |
| 大哥、姐（不是亲的） | *Big Brother*、*Sister* | 叫名字；黑帮戏里 *boss* |
| 叔叔、阿姨（不是亲的） | *Uncle*、*Auntie* | 名字，或者 *Mr. / Mrs.*；移民家庭里保留 *Auntie* 是对的 |
| 师傅 | *Master* | *Excuse me*，或者不叫 |
| 少爷 | *Young Master* | 写实用名字或 *sir*；**网文和短剧的观众已经习惯 *Young Master*，这是层的选择，问用户** |

| 日语 | 翻译腔 | 处理 |
|---|---|---|
| 田中先輩 | *Senpai Tanaka*（*senpai* 本身在动漫观众里通行，看层） | 叫名字，或者写清前后辈关系 |
| 〜さん、〜くん | 保留还是去掉 | 字幕的常见分歧，**问用户**：给谁看、什么风格 |
| 中文「你」→ 日语 | 全写成あなた | 按 `ja/01` 用职务、名字或省略 |

## 七、检查

交付前过一遍：

- 每处都标了上下，两头配得上；
- 每处都有结论；`错` 都有依据和等级。
- 依据里没有把模型记忆写成信源；引原著时核过**谁对谁说**，别的身份之间的例子不能直接搬。
- `拿不准` 都问过了，或者标了「待决定」并保留原文。
- 除了称谓和列出的连带改动，台词一个字没动。
- 称谓决定表写了，改口的地方写进了「例外」。
