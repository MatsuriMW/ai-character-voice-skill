# 架空王朝

架空不等于随便写。**历史剧要对得上史料，架空剧要对得上自己**：标准从「准不准」变成「一不一致」。观众不会查《明史》，但前一场叫官家、下一场叫皇阿玛，谁都听得出来。

---

## 一、先选一档

| 档 | 做法 | 适合 |
|---|---|---|
| **贴朝代**（默认） | 称谓和制度全按一个朝代，只换国号、人名、地名 | 权谋、正剧感、宅斗 |
| **拼合** | 从不同朝代挑词，但**每个位子只留一个词**，写进锁定表 | 古偶、古装短剧 |
| **自造** | 有自造的官职和敬称，其余贴一个朝代 | 世界观本身是看点的戏 |

拿不准就选贴朝代，依托选明代：观众最熟，称谓最不容易错。

### 依托选哪个朝代

| 依托 | 观众的感觉 | 代表叫法 | 注意 |
|---|---|---|---|
| 类汉魏、南北朝 | 古朴、士族气 | 陛下、君、卿、公、将军 | 不用老爷、小姐 |
| 类唐 | 开阔、胡风 | 圣人、阿耶、阿娘、郎君、娘子 | 观众不熟，点几个就够 |
| 类宋 | 文气、市井 | 官家、相公（宰相）、官人、小娘子 | 官家一出口就是宋味 |
| **类明** | 最通行的古装 | 皇上、大人、老爷、小姐、公子 | 默认 |
| 类清 | 森严、主奴分明 | 主子、奴才、阿哥、福晋 | 满俗很重，除非设定里有这样的王朝，否则少用 |

查词：`中文古代.md` 第三节；明、清看 `中文明清民国.md`。

## 二、称谓锁定表（必写）

开写前填好，放在**项目的总设定**里，所有角色共用。每行只留一个词；有例外就写明谁、什么时候。

```markdown
## <国号> 称谓锁定表　依托：<类明 / 拼合 / 自造>

| 位子 | 当面叫 | 自称 | 例外 |
|---|---|---|---|
| 皇帝 | 陛下 | 朕 | 太监私下叫万岁爷 |
| 皇后、妃 | 娘娘 | 本宫 | |
| 太子、亲王 | 殿下、王爷 | 本宫、本王 | |
| 公主 | 公主、殿下 | 本宫 | |
| 太监、宫女 | 公公、姑姑 | 奴才 / 奴婢（选一个） | |
| 宰相级 | 相爷 / 阁老（选一个） | 老夫、本相 | |
| 地方官 | 大人 | 本官、下官 | |
| 武将 | 将军 | 末将 | |
| 贵女 | 小姐 / 娘子（选一个） | 小女子 | |
| 贵公子 | 公子 | 在下 | |
| 夫妻 | 夫君、夫人 | | |
| 父母 | 父亲、母亲 / 爹、娘 | | 看门第 |
| 平民对官 | 大人 / 老爷（选一个） | 草民、小人 | |
| 骂人 | | | 不用现实里有出处的 |
```

**拼合档最容易犯的错**：同一个位子两个词来回跳（大人和老爷、娘娘和主子），这时候观众会以为两个人身份不同。要跳就让它有含义：只有心腹才叫「主子」。

## 三、架空才有的问题

每条都要当场定下来，写进锁定表下面。

| 问题 | 选项 | 不定会出什么事 |
|---|---|---|
| **真实历史算不算数** | ① 算到某个朝代为止（有孔孟、有诗经）；② 只留没有出处的俗语；③ 全部替换（自造圣贤和经书） | 架空的国家里有人说「司马昭之心」「三顾茅庐」 |
| **成语和典故** | 跟上一条走。选②③时，**带人名地名的成语一律换**（东施效颦、暗度陈仓、四面楚歌） | 同上 |
| **地名** | 自造；或者只留泛称（江南、塞北、京城） | 架空的国里出现长安、蜀地 |
| **宗教** | 佛道有没有；没有的话，阿弥陀佛、无量天尊都不能说，改成老天爷、苍天在上 | 没有佛教的世界里有和尚 |
| **计量和时间** | 默认沿用时辰、更、里、两、文，不用改 | 自造历法，观众听不懂 |
| **年号和国姓** | 定下来；国姓避讳可以当戏来写 | |
| **边地、异族** | 自造族名；用语法和词表示地域（俺、咱），不提东北、山东这些现实地名 | 架空世界里有「东北话」 |

### 自造词的规矩

1. **看字面能懂**：镇北王、掌印女官、巡夜司。观众第一次听就能猜到。
2. **用旧字造**，不写生造的音译。
3. **一部戏不超过五个**，其余都用现成的。
4. **第一次出现要带着戏**：让别人对他行礼、怕他，不要让角色解释（「你可知掌印女官是何等身份？」）。

## 四、架空不是挡箭牌

- **现代词照样穿帮**。除非是戏说层，架空的国家里也不说「压力」「内耗」「我觉得」。脚本照跑。
- **身份差别照样要有**。架空不影响平民、官员、草寇说话不一样（`中文古代.md` 第二节）。
- 选了贴朝代，就别混别的朝代：类明的戏不叫官家。
- 仙侠、玄幻的宗门称谓（师尊、道友、长老）不是王朝体系，做法一样：单写一张锁定表。

## 五、英文和日语

- **英文**：奇幻王国依托一个时期（`英文古代.md` 第一节），称呼（*my lord*、*Your Grace*）加上少缩写；自造头衔的规矩同上。
- **日语**：现实风格依托江户或战国（`日语古代.md`）；二次元和奇幻看 `../ja/05-役割语与二次元.md`。

## 六、检查

```bash
python3 scripts/yuyan_tool.py era 台词.md --lang zh                  # 拼合、自造档
python3 scripts/yuyan_tool.py era 台词.md --lang zh --period ming    # 贴朝代档，查依托的朝代
```

脚本查不了一致性。人工过：把锁定表里每个位子的词在剧本里搜一遍，看有没有跳；带人名地名的成语挑出来对照第三节的选择。
