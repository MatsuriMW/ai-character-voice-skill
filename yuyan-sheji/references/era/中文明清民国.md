# 中文：明、清、民国

这三朝离观众最近，影视最多，也最容易叫错。每朝先看「最大的变量」，再查称谓表。

**标记**：没标的来自原著或笔记（`../sources.md`）；〔影视〕= 影视通行、史料里少见，通行层可以用，考据层不用；〔待核〕= 没核到。

称谓都分三层看（`00-时代轴.md`）：**考据层**照表；**通行层**可以用〔影视〕的词，但一部戏里要一致；**戏说层**随意。

---

## 一、明

**最大的变量：官场按品级和场合分档，不是一律「大人」。** 明代官场最尊的称呼是「老先生」，「大人」反而不是默认。通行层一律叫大人也没人挑，考据层要换。

### 皇室和内廷

| 对象 | 怎么叫 | 说明 |
|---|---|---|
| 皇帝（外臣面奏） | 陛下、皇上 | 自称：臣 |
| 皇帝（太监、宫人） | **万岁爷、皇爷、爷爷** | 太监说「爷」是明宫口吻；提前代皇帝说「太祖老爷」「神庙老爷」 |
| 皇帝（皇子） | 父皇（正式）、**爹爹**（亲近时） | 不用「皇阿玛」 |
| 太子、亲王 | 殿下、千岁、王爷 | |
| 太监自称 | **奴婢**（上奏、对主子）、咱、咱家 | 「杂家」是戏曲和影视的读法〔影视〕；「奴才」在明代不是太监的标准自称 |
| 太监被称 | 公公、老公（北方俗称，这时候指太监）、厂公、督公（东厂提督）〔影视味重〕 | 魏忠贤时才有「九千岁」 |
| 后妃 | 娘娘；自称臣妾、妾 | 「本宫」〔影视〕 |

### 官场

| 场合 | 叫法 |
|---|---|
| 京官之间（内阁到九卿） | **老先生**；门生称座师也这么叫 |
| 阁臣 | 阁老、元辅、首辅、相公（雅）、中堂 |
| 外官对巡抚 / 对巡按 | 老先生 / 先生、大人 |
| 老爷 | 九卿、翰林、外任司道以上；再往下只称爷，乡间称老爹 |
| 知县 | 士绅叫县父母（《儒林外史》）、老父母（只见到转引）、父母官；百姓叫大老爷〔待核，通行说法〕 |
| 给事中 / 御史 | 掌科 / 道长 |
| 武官 | 把总、千总一类叫总爷；百姓叫军爷 |

| 自称 | 对谁 |
|---|---|
| 臣 | 皇帝 |
| 下官、卑职 | 上官 |
| **晚生**、侍生 | 前辈、乡绅、高位者（也写在拜帖上） |
| **门生** | 座师（主考官） |
| 生员 | 秀才对官 |
| 童生 | 没考中的读书人对考官 |

### 读书人：身份一变，称呼当场变

《儒林外史》的范进最能说明问题：报喜前邻居叫他**范相公**，报喜后立刻叫**范老爷**，连岳父胡屠户都改口叫**贤婿老爷**。张乡绅来拜，叫他**世先生**，他自称**晚生**，称对方**老先生**。

- 秀才：相公。举人、进士：老爷。写科举戏，改口这一下就是戏。
- 同科：年兄；世交：世兄、世先生；同乡：桑梓。

### 女眷和市井

| 对象 | 叫法 |
|---|---|
| 贵女 | 小姐（明代已是贵称） |
| 官员妻、母 | 夫人、太太、老太太 |
| 平民妻 | 娘子、大娘子（正妻） |
| 女子自称（话本味） | 奴、奴家、妾身 |
| 丈夫 | 相公、官人 |
| 有钱有势的男人 | 大官人、员外、老爹 |
| 老年妇人 | 干娘、妈妈（也指鸨母）、老身（自称） |
| 店里 | 客官；店家、掌柜、小二 |
| 平民自称 | 俺、咱、小人、小的 |

**话本腔**（考据层或要明味时点一点，多了观众听不懂）：怎的、甚么、恁地、端的、便了、则个。

### 明代常见穿帮

奴才（太监自称时）、皇阿玛、格格、贝勒、福晋、嗻、军机处。

## 二、清

**最大的变量：满汉有别，前期和晚清有别。** 同一句话，满臣、汉臣说出来不一样；康熙朝和光绪朝官场腔也不一样。

### 奴才和臣：最常见的错

| 人 | 对皇帝自称 |
|---|---|
| **汉人文官** | **臣**。汉臣自称奴才是错的 |
| 满、蒙、汉军旗官员 | 公事称臣，请安谢恩称奴才（乾隆定的规矩）；日子久了满臣多一律称奴才 |
| 上面这些人和汉臣联名上奏 | 一律称臣 |
| 汉人提督、总兵（武职） | 奴才 |
| 太监、包衣、王府属员和奴仆 | 奴才（对主子） |

所以戏里可以这样分：满臣跪下说「奴才」，旁边的汉臣说「臣」，一句话交代两个人的身份。

### 皇室

| 对象 | 怎么叫 | 说明 |
|---|---|---|
| 皇帝 | 皇上；万岁爷（太监、宫人）；**主子**（旗人、太监） | |
| 皇帝（子女称） | **汗阿玛**、皇父 | **「皇阿玛」史料里没有**，是清宫剧叫开的〔影视〕 |
| 皇子 | 阿哥（四阿哥），指还没封爵的；封了就叫爵位（王爷、贝勒爷） | |
| 皇帝的女儿 | **公主**：皇后所生固伦公主，妃嫔所生和硕公主 | **不叫格格**。「还珠格格」是影视 |
| 格格 | 王公的女儿（亲王之女和硕格格，往下多罗、固山）；满人日常也泛称年轻女子；王府里没名分的妾也叫格格 | |
| 福晋 | 亲王、郡王、贝勒的正妻；侧福晋 | |
| 后妃 | 娘娘；「本宫」「小主」〔影视〕 | |
| 太后 | 老佛爷（晚清宫中称慈禧）；不是所有太后都这么叫 | |
| 太监 | 自称奴才；被称公公；应答「嗻」 | 影视常写成「喳」 |

「皇上吉祥」「跪安吧」多半是清宫剧的说法〔待核〕，折子上请安写「恭请圣安」。

### 官场

| 职务 | 背后、公文里 | 当面（晚清） |
|---|---|---|
| 大学士 | 中堂、相国 | 中堂 |
| 总督 | 制台、制军 | 大人（下属称督抚司道都叫大人） |
| 巡抚 | 抚台 | 大人 |
| 布政使 / 按察使 | 藩台 / 臬台 | 大人 |
| 道员 | 道台 | 大人 |
| 提督 | 军门 | 军门 |
| 知府 | 府台、太尊 | 大老爷 |
| 知县 | 县尊 | 太爷（日常）、大老爷（公堂）；详见下面 |
| 佐杂小官 | | 老爷；典史也被叫太爷（《官场现形记》的钱典史） |
| 幕僚 | 师爷 | 老夫子 |

称呼有过一轮一轮的「通货膨胀」：清前中期知府、知县称太老爷，到晚清知县也成了大老爷，各家说法不完全一致〔待核〕。

**晚清知县怎么叫（写实戏的默认）**：这张表是作者定的口径，**没有查到一手出处**（`../sources.md`）。戏里直接照用，不用再问；要做到考据层，再去核。

| 谁 | 当面怎么叫知县 |
|---|---|
| 衙役、皂隶、百姓（日常） | 太爷、本县太爷 |
| 衙役、百姓（公堂、诉讼、拦路告状） | 大老爷 |
| 有功名的缙绅、高级幕友 | 老太爷、县尊、姓 + 太爷（王太爷） |
| 上司（知府、道员、总督） | 知县、贵县 |
| 同级（别县知县） | 老兄、仁兄（私下）；县尊（正式） |

留意：**太爷不只给知县**，《官场现形记》的典史也叫钱太爷。知县和典史同场时，别都写成「姓 + 太爷」，观众分不清。

| 自称 | 用在 |
|---|---|
| 卑职、卑府、卑县 | 文官对上司 |
| 标下 | 武官对上司 |
| **兄弟** | 晚清官场对同僚、对下属的官腔，自谦里带亲热 |
| 老哥、吾兄、老兄 | 称对方，同上 |
| 职道 | 道员对巡抚 |

《官场现形记》第四回里，署理巡抚对道台说「兄弟就打了一个电报」，称他吾兄、老兄；道台对巡抚自称职道；巡捕对道台自称卑职。上司越客气，越要小心。

### 家里（《红楼梦》的叫法）

| 对象 | 叫法 |
|---|---|
| 未嫁的女儿 | **姑娘**（林姑娘）；贵族家不是只叫小姐 |
| 少爷 | 按排行叫二爷（宝二爷）；少爷 |
| 已婚的 | 奶奶（琏二奶奶）、太太、老太太 |
| 长辈叫晚辈 | 我的儿 |
| 晚辈哄老太太 | 老祖宗 |

**清代口味**：句末「罢」「罢了」「呢」，「横竖」「可不是」；嗳哟、啐（女子嗔骂）、阿弥陀佛（老太太、夫人脱口）。北京话里已有「你老」，后来有「您」。

### 清代常见穿帮

官家、锦衣卫、东厂、首辅（当实权职务说时）；汉臣说奴才；管皇帝的女儿叫格格。

## 三、民国

**最大的变量：新旧两套称呼同时在用。** 1912 年政府明令废掉大人、老爷，规定官场称官职、民间称先生或君；可是 1921 年鲁迅笔下的闰土见了儿时伙伴，还是恭恭敬敬一声「老爷」。**谁用哪一套，就是这个人的立场**：新派、旧派、想往上爬的、不敢改口的。

民国不算古代，下意识反应和 filler 照现代的做法写（`../07a-脱口而出与填充词.md`），只是词要换成那个年代的。

### 先定地方和年份

| | 北洋（1912–1928） | 南京十年、抗战、内战（1928–1949） |
|---|---|---|
| 官场 | 大帅、督军、总长；帅府味 | 委员长、部长、局长；党腔（同志、革命） |
| 城市 | 辫子刚剪，新旧冲突最猛 | 上海摩登，电影、舞厅、洋行 |

| 地方 | 味道 |
|---|---|
| 上海 | 先生、小姐、师母、老板；吴语加洋泾浜（下面） |
| 北平 | 您、爷、您呐；礼数周到，旗人遗风 |
| 东北 | 胡子（土匪）、大当家；「妈了个巴子」（奉系军人的招牌，通行说法） |
| 乡下 | 老爷、东家、少爷，基本没变 |

### 新的一套

| 称呼 | 用在 | 说明 |
|---|---|---|
| 先生 | 男性通称；**老师，女老师也叫先生**；对高位女性也可 | |
| 君 | 文人之间，书面多 | |
| 小姐、女士 | 未婚、新式女性 | |
| 太太 | 已婚 | 也叫某师母（上海，对熟人） |
| 密斯、密斯脱 | 上海、学校，时髦 | 密斯王 |
| 同学 | 学生之间 | |
| 同志 | **国共党内和革命者之间**，不用来叫路人 | |
| 老板、老板娘 | 小店业主也叫 | 民国就有，不算穿帮 |

自称：敝人、鄙人（演讲、老派）；**兄弟**（演讲、官场，「兄弟今天来讲几句」）；学生（对老师、上司）；我。

夫妻互相介绍：内人、内子、太太、我们家那位；外子（书面）、我先生、当家的、孩子他爹。**「爱人」不行**。

### 旧的一套（一直在用）

老爷、太太、少爷、少奶奶、姨太太、老太爷（大家族）；太爷（乡绅，《阿Q正传》的赵太爷）；东家、掌柜的、账房、伙计、堂倌、茶房；张妈、李妈（女佣）；车夫叫乘客先生、老爷。

### 军政：「座」不要乱用

| 叫法 | 情况 |
|---|---|
| **委座** | 抗战时期将领对蒋介石的尊称，电报和日记里都有；1945 年以后不再用 |
| **钧座** | 下级对上级的书面尊称，民间写信给长官也用，北洋时就有 |
| 军座、师座、团座 | 一手史料里很少，老兵回忆都说「我们师长」〔影视〕 |
| 局座、处座 | 影视发明的〔影视〕 |
| 校长 | 只有黄埔系叫蒋介石校长；别的派系叫委员长 |
| 委员长 | 1932–1945，抗战胜利后还叫就是穿帮 |
| 大帅 | 北洋军阀 |
| 老总 | 百姓叫当兵的 |
| 职 | 下级电文里的自称（「职等誓以一死」） |
| 字 + 兄 | **同辈之间，或资深者对资浅者**（「敬之兄」）；下级不能这样叫上级，资浅的也不能这样叫前辈 |

### 上海的洋泾浜（点一两个就够）

水门汀（水泥）、德律风（电话）、麦克麦克（很多）、门槛精（精明）、瘪三、白相、摩登。

### 骂人和脱口

阿呀（江浙，《祝福》《故乡》里都是）、妈妈的（《阿Q正传》）、他妈的；娘希匹（宁波奉化一带，通行说法）。

### 民国常见穿帮

爱人、对象（恋爱义）、单位、领导（称上级）、师傅（泛称陌生人）、同志（叫路人）、小姐姐；局座、处座。

**反过来也要小心**：电话、开会、分钟、老板、谢谢、再见这些在民国都是对的，脚本要加 `--period minguo`，不然会误报。

## 四、同一句话，三朝（「这事办不了」）

| 谁对谁 | 说法 |
|---|---|
| 明，翰林对内阁大学士 | 老先生明鉴，此事晚生实难从命。 |
| 明，秀才对知县 | 老父母在上，此事生员委实担当不起。 |
| 清，汉臣对皇帝 | 臣愚以为，此事恐有窒碍。 |
| 清，满臣对皇帝（请安折的口吻） | 奴才愚见，此事怕是难办。 |
| 清，知县对知府 | 回大老爷，这事卑职实在办不下来。 |
| 清，巡抚对道台 | 老兄，兄弟也有兄弟的难处，这事就先搁一搁罢。 |
| 清，巡抚对知县 | 贵县不必再说，这事先搁一搁罢。 |
| 民国，上海职员对洋行老板 | 老板，这桩事体真真难办。 |
| 民国，师长电报给蒋介石 | 职部实难遵办，恳请钧座收回成命。 |
| 民国，师长私下对同辈 | 子明兄，这事我办不了，你别难为我。 |
