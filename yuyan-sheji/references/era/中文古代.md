# 中文古代

**提醒**：称谓随朝代变化很大，同一个词在不同朝代意思不一样，影视里的说法也不等于史实。这里按「通行古装」打底，朝代差别在第三节。**明、清、民国看 `中文明清民国.md`；架空王朝看 `架空王朝.md`。** 考据层要另外核，放进〔待核〕。

---

## 一、核心规矩

1. **称谓决定一切**。先定自称和对称，古人很少用「我」「你」直来直去（平民和草寇除外）。
2. **自称称名，称人称字**（士人之间的礼法，平民和草寇不讲这个；随朝代和关系变化）：平辈之间叫字或号，长辈叫晚辈的名；直呼对方的名是失礼，甚至是挑衅。
3. **对上自贬，对人抬高**：鄙人、拙荆、犬子、寒舍；令尊、令郎、贵府、高见、尊驾。
4. **先礼后事**：见面先客套，拒绝先谢。
5. **文白比例就是阶层**：越读书越文，越底层越白。官员写奏章文言，说家常也还是白话。
6. **不要满嘴之乎者也**：「在下」「姑娘」这些词加上现代句式，就是最常见的假古装。

## 二、各身份的语言体系

### 帝王、皇室

| 项 | 内容 |
|---|---|
| 自称 | 朕（秦以后皇帝专用）；寡人、孤（王、诸侯，影视也用于太子、亲王）；本王、本宫（影视通行：皇后、妃、太子、公主）；哀家（戏曲里的太后、寡居皇后） |
| 被称 | 陛下、皇上、圣上、万岁；**宋代叫官家**，唐代宫中叫大家、圣人 |
| 对下 | 爱卿、卿、尔等、平身、退朝、准奏、拿下 |
| 下对上 | 臣、微臣、臣妾、儿臣；奴才（**清代**旗人和太监，汉臣不用）；启奏、遵旨、万岁万万岁 |
| 说话 | 短。少解释，不说「请」。 |

### 官员

| 项 | 内容 |
|---|---|
| 自称 | 对上：下官、卑职（低级官）、臣；对下：本官、本府（知府）、本县（县令）、本帅；老年：老夫、老朽 |
| 称人 | 大人、老爷、相公（宋代多指宰相）、阁老（明）、中堂（明清，清代最盛）；**同科中式的才叫年兄**，一般同僚叫某兄、某大人；老师：恩师 |
| 句式 | 依下官之见、下官以为、此事断不可行、还望大人明察、不敢、有劳 |
| 公堂 | 来人、带上堂来、大胆、从实招来 |
| 规矩 | 文白相间；不把话说死（此事容后再议）；**官场话越客气越狠**；引经书 |

### 士人、书生

| 项 | 内容 |
|---|---|
| 自称 | 小生、晚生、学生（对老师、长官，明清）、在下、不才、愚兄、小弟 |
| 称人 | 兄台、仁兄、贤弟、先生、足下、阁下、称字 |
| 句式 | 子曰、古人云、岂不闻、此言差矣、失敬失敬、久仰 |
| 规矩 | 掉书袋，**但穷书生和老夫子不一样**：年轻的偶尔冒傻气，迂腐的句句引经 |

### 官家女子、闺秀

| 项 | 内容 |
|---|---|
| 自称 | 对父母：女儿；对外人：小女子、奴家（元明话本常见，民女也用）；已婚：妾、妾身；贵女在下人面前：我、本小姐（影视味） |
| 称人 | 爹爹、娘、母亲、父亲（雅）；公子、先生；丫鬟名；丈夫：夫君（通行）、郎君（唐）、官人（宋）、相公（明清） |
| 被称 | 小姐（**明清**才是贵小姐的意思；宋元多指地位低的女子）、姑娘；**唐宋**用娘子、小娘子 |
| 句式 | 有劳、多谢公子、此事恐怕不妥、女儿不敢、还请父亲三思 |
| 规矩 | **含蓄**：不直说想要，不直说喜欢；生气也是话少；读书的有诗词底子；对丫鬟放松。「公子请自重」是通行台词，别太频繁 |

### 平民

| 项 | 内容 |
|---|---|
| 自称 | 俺（北方，宋金元以后）、咱、我；对官：小人、小的（明清）、草民（影视通行）、民女、老汉、老身（老妇） |
| 称人 | 大哥、嫂子、大娘、大爷、小哥、官人（宋元对男子的尊称）、掌柜的、东家、青天大老爷 |
| 句式 | 短句，全白话，俗语：可不敢、这可咋办、求老爷做主、老天爷 |
| 比喻 | 庄稼、牲口、灶台、天气 |
| 规矩 | **不会文言词**，会把文词说错或听不懂；对官话很短、不敢抬头（公堂上才跪，平时见官不必默认写跪）；自己人之间话多 |

### 商贾、店家

| 项 | 内容 |
|---|---|
| 自称 | 小的、小人、在下（有钱之后） |
| 称人 | 客官、官人、爷、老爷、夫人 |
| 句式 | 客官里边请、您老（**「您」元明以后才有迹象，通行层也不算错，但考据层慎用**）、好说好说、小本生意 |
| 规矩 | 说话热络，先称呼后开价；「打尖还是住店」是影视套话，可以用，但要知道是套话 |

### 草寇、强盗、江湖

| 项 | 内容 |
|---|---|
| 自称 | 洒家（《水浒传》里鲁智深等关西人的自称）、俺、老子、爷爷（自夸：你爷爷我）、小爷；讲规矩时：在下 |
| 称人 | 你这厮、兀那（元明话本：那个）、小子、鸟人、撮鸟、直娘贼（《水浒》的骂法）；自己人：哥哥、兄弟、大王、寨主、当家的 |
| 句式 | 休要聒噪、留下买路财、此山是我开此树是我栽（套话）、不打不相识、大碗喝酒大块吃肉、替天行道、风紧扯呼（武侠小说味） |
| 规矩 | **骂人当招呼**；对寨中上下讲义气，有座次；对读书人又瞧不起又有点怕；**不是所有土匪都一个腔**：落魄军官、读书人上山，说话还带原来的底子，这点最有戏 |

### 僧道、军人、仆婢、太监

| 身份 | 自称 | 称人 | 招牌 |
|---|---|---|---|
| 和尚 | 贫僧、老衲 | 施主、居士 | 阿弥陀佛、善哉 |
| 尼姑 | 贫尼 | 施主 | 阿弥陀佛 |
| 道士 | 贫道 | 施主、道友 | 无量天尊（通行） |
| 武将 | 末将、标下（清）、属下 | 将军、元帅、大帅 | 得令、领命 |
| 丫鬟 | 奴婢、婢子 | 小姐、夫人 | 小姐您快看 |
| 小厮、家丁 | 小的、奴才 | 老爷、少爷、公子 | |
| 老仆 | 老奴 | 少爷（从小叫到老） | |
| 太监 | 奴才（清）、奴婢（明）、咱家、杂家（影视） | 万岁爷、皇爷（明）、主子（清）、娘娘 | 嗻（清，满语来源）、皇上驾到 |

## 三、朝代差别

先定朝代，再查这张表；明、清、民国在 `中文明清民国.md` 里写得更细。〔通行知识，考据层要核〕

| 朝代 | 皇帝被称 | 官员 | 男子 | 女子 | 父母、丈夫 | 这时候不用 |
|---|---|---|---|---|---|---|
| **先秦** | 王、君、大王；寡人、孤（自称） | 大夫、卿、子 | 子、君、先生 | 女、夫人 | 父、母；君子、良人 | 皇上、陛下（秦以前）、老爷、小姐 |
| **秦汉** | 陛下、县官（汉代口语）；朕 | 君、公、丞相；明公 | 君、足下、郎 | 夫人 | 大人（汉代可称父母）；夫君 | 皇上、老爷、小姐、相公 |
| **魏晋南北朝** | 陛下、至尊、官家（六朝已见）；朕 | 明公、使君（州郡长官）、府君 | 卿（亲近互称）、郎、阿某 | 娘、女郎 | 阿翁、阿母；卿 | 老爷、小姐、相公 |
| **隋唐** | 圣人、大家、陛下；宫中也自称「我」 | 相公（宰相）、某郎、明府（县令） | 郎君、某几郎（称排行） | 娘子、某几娘 | 阿耶、耶耶、阿娘；郎君 | 老爷、小姐 |
| **宋** | **官家**、陛下 | 相公（宰相）、官人（有官的、也泛称）、衙内（官家子弟） | 官人、某几郎、员外 | 小娘子、娘子；小姐多指地位低的女子 | 爹爹、妈妈；官人 | 老爷（少）、大人（少）、奴才 |
| **元** | 皇帝、万岁；有蒙古语词（那颜） | 相公、大人（渐多）、老爷（渐多） | 官人、舍人 | 小姐开始变贵称、娘子 | 爹、娘；俺、咱大量进口语 | 奴才（作自称） |
| **明** | 皇上、万岁爷 | 老先生、老爷、大人 | 相公（秀才）、官人、员外 | 小姐（贵）、娘子 | 爹、娘；相公 | 格格、皇阿玛、嗻 |
| **清** | 皇上、主子 | 大人、大老爷、中堂 | 爷、少爷、老爷 | 姑娘、小姐、奶奶 | 阿玛、额娘（满）；爹、娘；老爷 | 官家、锦衣卫 |
| **民国** | （无） | 先生、长官、委座 | 先生、少爷、老爷 | 小姐、太太、女士 | 爸爸、妈妈、爹、娘；先生 | 爱人、对象、单位 |

每行都是这个朝代的**底色**，不是全部。「大人」作官员的敬称是越往后越泛，「小姐」的贵贱在宋元之间翻了个面：这两个词在宋以前的戏里尤其要小心。

架空王朝不用对史料，但一部戏里要自洽：不能既叫官家又叫皇阿玛。怎么选，看 `架空王朝.md`。

## 五、同一句话，四个人（「这事不能这么办」）

| 人 | 说法 |
|---|---|
| 平民老农（对官） | 大老爷，这、这可使不得呀，俺一家老小就指着这几亩地…… |
| 官家小姐（对父亲） | 爹爹，此事恐怕不妥，还请爹爹三思。 |
| 官员（对同僚） | 此事断不可行。若贸然上奏，你我都担待不起。 |
| 草寇（对手下） | 放屁！这般干法，兄弟们都得掉脑袋！ |

差别不只在称谓：**平民带着具体的怕（地），闺秀先缓后说，官员讲利害和后果，草寇直接骂**。
