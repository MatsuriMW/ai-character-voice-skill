# 关西腔和地方口音

日语里地方口音差别很大，尤其是关西腔：不只是换句末，否定、断定、说明语气、敬语、词汇和声调都不一样。日本观众对关西腔又最挑剔，**写错、念错的假关西腔（エセ関西弁）比不写更出戏**。

**下面的例句都要标〔待核〕，发布前请当地人听。**

---

## 一、「关西腔」不是一种话

日常说「关西弁」，多半指大阪一带的话。其实内部有差别，写之前先定他是哪里人、多大岁数。

| 地方 | 特征 | 写给谁 |
|---|---|---|
| 大阪市及周边 | 影视里的「标准关西腔」；〜や、〜ねん、〜へん、めっちゃ | 默认 |
| 河内（大阪东部） | 更粗、更冲：〜やんけ、ワレ、おんどれ。电影里的硬汉味 | 工厂、街头、黑帮片；当心刻板 |
| 泉州（大阪南部，岸和田一带） | 也粗，语气快，〜やんけ、〜ちゃうんけ | 同上 |
| 船场（老商家） | 慢而礼貌，老派大阪商人的话；〜でございます、ごりょんさん、いとはん。**现在用的人很少** | 年代戏、老铺世家 |
| 京都 | 柔、慢，〜はる 多，否定 〜ひん、句尾 〜え。「〜どす」现实基本只在花街和老派的人嘴里 | 京都人、老铺 |
| 神户 | 和大阪接近，但进行体说 〜とう（何しとう？）、〜とん | 神户年轻人的标记 |
| 奈良、和歌山 | 和大阪接近，各有差异。没把握就按大阪写，少用地方词 | |

**世代差比地域差大**：研究也说，传统方言衰退后，世代差别比地区差别更明显。

| 年龄 | 说法 |
|---|---|
| 老人 | 〜さかい、〜はる、おおきに，部分老词 |
| 中年 | 典型大阪话 |
| 年轻人 | 词更接近标准语，但**否定、声调、ほんま、めっちゃ、あかん 还在**；也会混入东京词（〜じゃん 少，〜やん 多） |

## 二、语法对照（最重要）

假关西腔通常只换了句末，这张表是真正要换的地方。

| 东京话 | 关西（大阪） | 例 | 注意 |
|---|---|---|---|
| 〜だ | 〜や | そうや、雨や | 连续的、浓度高的大阪话里，普通断定用 や；个别「だ」要看人和场合（有人切换标准语） |
| 〜だよ | 〜やで | 明日やで | |
| 〜だね | 〜やな、〜やね | ええ天気やな | |
| 〜でしょ、〜だろ | 〜やろ | そうやろ？ | |
| 〜じゃん | 〜やん、〜やんか | ええやん | |
| 〜じゃない | 〜ちゃう？、〜やないか | それ、ちゃう？ | |
| 違う | ちゃう | ちゃうちゃう | 关西腔最响的一个词 |
| 〜んだ、〜のだ | 〜ねん | 行くねん、好きやねん | 说明、强调 |
| 〜たんだ | 〜てん | 言うてん、やってん | |
| 〜の？ | 〜ん？、〜の？ | 何しとん？ | |
| 〜ない | 〜へん、〜ん | 行かへん、知らん | 动词否定都要换 |
| 〜なかった | 〜へんかった、〜んかった | 知らんかった | |
| 〜ない？（邀约） | 〜へん？ | 行かへん？ | |
| ない（没有） | あらへん、ない | お金あらへん | |
| 形容词否定 | 寒ない、おもんない | | 也会变，具体形式随词和地区而异，没把握就保留 〜くない |
| 来ない | けえへん（大阪）、きいひん（京都）、こおへん（神户） | | 这三个是经典的地方标记 |
| しない | せえへん（大阪）、しいひん（京都） | | |
| 〜ている | 〜てる、〜とる（西日本多地都有，语气看人和上下文）、〜とう（神户） | 何してんの、何しとんねん | |
| 〜ておく | 〜とく | やっとくわ | |
| 〜てしまった | 〜てもた、〜てしもた | 忘れてもた | |
| 〜てあげる | 〜たる | やったるわ | 「〜たろか」是威胁，也是好意 |
| 言った | 言うた | 言うたやん | う音便：買うた、思うた 同 |
| 〜なきゃ | 〜なあかん | 行かなあかん | |
| だめ | あかん | それはあかん | |
| そうだ | せや、そや | せやな | |
| じゃあ | ほな | ほな、行こか | |
| しよう | しよ、しよか | 行こか | |
| から（理由） | 〜から；老派 〜さかい、〜よって | 忙しいから | **年轻人主要用 から**，さかい 偏老 |
| けど | けど、けどな | | |
| 〜って（引用） | 部分结构里说 て，或者省掉 | | **不能机械替换**：受后面接的「言う、思う」等影响。没把握就保留标准形 |
| 〜で（句末） | 告知、提醒 | 行くで、あるで | 和标准语 よ 相近，但不是一一对应 |
| 〜わ（句末） | 下决心、感慨；**下降调，男女都用** | 行くわ、もうええわ | 不是每个 よ 都能换成 わ |
| 〜ね | 〜な、〜なあ | | |
| 很 | めっちゃ、ごっつ、えらい | | |
| いい | ええ | ええで | |

| 〜ください（亲近的请求） | 〜てくれへん？、〜てや | 待ってや | |
| 〜な（禁止） | 〜な、〜たらあかん | 行ったらあかん | |

## 三、敬语：〜はる 和关西的敬体

| 形 | 用法 | 例 |
|---|---|---|
| 〜はる | **轻敬语**，说第三人和对方，亲近而尊重；京都用得比大阪多 | 先生が言うてはった。どこ行かはるん？ |
| 〜ですねん、〜ますねん | 关西的敬体说明 | そうですねん。 |
| 〜ですやん | 亲近的敬体反驳 | 言うたですやん（较随便） |
| 〜ですわ、〜ますわ | **下降调的男女通用说法，不是大小姐语** | そうですわ。 |
| 〜でっか、〜まっか、〜でんな、〜まんな | 老商人腔；现在多半是玩笑 | もうかりまっか |
| 〜ておくれやす、〜なはれ | 老派、京都、古装味 | おいでやす |

**商务场合**：现代大阪人对东京客户多半说标准敬语 + 关西声调，个别句尾漏出来（`〜ですわ`、`ほんまに`）。「尊敬语、谦让语、内外」的规矩不变（`02`）。不要写成满口「〜でんがな」的生意人。

## 四、人称

| 项 | 关西 | 注意 |
|---|---|---|
| 自称 | 俺、僕、わし（中老年男）、うち（女，各年龄都有）、わて、あて（老） | わし 在关西是真话，不算役割语 |
| 你 | あんた、自分（！）、お前、兄ちゃん、姉ちゃん、おっちゃん、おばちゃん | **关西话里「自分」就是「你」**：自分どこの人？ |
| 粗 | ワレ、おどれ、おんどれ | 只限打架、黑帮 |

## 五、词汇（分三层）

| 层 | 词 | 说明 |
|---|---|---|
| **活的，放心用** | ほんま、あかん、めっちゃ、ちゃう、ええ、おもろい、しんどい（累）、なんぼ（多少）、しゃあない、ほな、せや、なんでやねん、ぼちぼち（还行）、アホ、マクド | 主要靠这层 |
| **活的，但偏地方、偏老** | ほかす（扔；兵库、奈良等，大阪也有 ほる）、なおす（收好）、かなん（受不了）、えげつない、ごっつ、えらい（累、很）、おおきに、まいど、どつく、しばく、いてまう、シュッとしてる（帅气）、飴ちゃん | 一场一个就够，飴ちゃん 已是刻板印象 |
| **基本是玩笑或役割语** | でんがな、まんがな、もうかりまっか、ぼちぼちでんな、〜だっか、〜やねん（每句都有） | 现实别用，喜剧才用 |

**アホ和バカ**：关西日常说アホ，亲昵也能说；バカ 听着更狠（东京相反）。这是常见说法，算刻板也算习惯，〔待核〕。

## 七、声调：做视频最大的坑

**字写成关西腔，TTS 和视频模型多半还是按东京声调念。** 这样出来就是最糟的假关西腔：词是关西的，调子是东京的。关西观众第一秒就听得出。

关西用**京阪式**声调，高低和东京常常相反或不同。常被举的例子（大阪）：

| 词 | 东京 | 大阪 |
|---|---|---|
| 橋（はし） | 低高 | 高低 |
| 箸（はし） | 高低 | 低高 |

雨、飴这组也常被提起，但关西的实际音高还受地点、单说还是带助词影响，不能简单写成高低对调。**这里只为说明东西两边不一样，不要拿来标具体台词的声调**，要靠当地人或试听。

其他差别：单拍词拉长（目→めー、手→てー、日→ひー）；母音念得更满，无声化少；句尾起伏更大。

**怎么办，按优先级**：

1. **最好**：真人关西配音，或者关西人的声音做参考音色（`peiyin`）。
2. **其次**：挑明确支持关西腔的模型，提示词写「大阪弁のイントネーション」，**必须试听**，并请关西人听一条。
3. **听着假就降级**：减少关西词，改成「标准语 + 个别词」，或者干脆把这个角色改成说标准语，只在字幕或人设里提他是大阪人。
4. **不要假定写对字就够了**。档案和交付都要写明：这条关西腔有没有经过试听。

念白版：关西词写假名（けえへん、ほんま、せや）；ん、へん 不要被引擎断开；汉字词容易按东京音念，引擎支持时用读音标注。

## 八、浓度和切换

每个关西角色要定：

| 项 | 例 |
|---|---|
| 地方 | 大阪市内、河内、京都…… |
| 浓度 | 0 标准语；1 标准语 + 声调和个别词；2 日常关西腔；3 浓（河内、老派） |
| 对谁变 | 对东京客户 1，对员工 3 |
| 什么时候漏 | 生气、喝酒、回老家 |
| 他的态度 | 骄傲、藏着、看场合当武器 |

**二次元和喜剧**：可以写夸张的关西人（〜やねん、なんでやねん、笑点担当）。这是役割语，别让关西角色只负责好笑。**写实**：别让他每句都逗哏。

## 九、自查

- 断定、否定、说明语气、理由是不是都换了？（只换句末＝假的）
- 高浓度的角色，有没有混进 だ、〜ない、〜じゃん、〜だよ？（有切换设定的除外）
- 有没有 でんがな、まんがな？
- 地方混了吗？（大阪人说「どす」，神户人说「〜はる」太多）
- 这条有没有试听？

## 十、其他地方（简表）

断定、否定、理由三处都要对。没把握就让他说标准语，只留一两个词（`06` 第五节）。

| 地方 | 自称 | 断定 | 否定 | 理由 | 招牌 | 注意 |
|---|---|---|---|---|---|---|
| 东京下町 | 俺、あたし | 〜だ、〜でい（老） | 〜ねえ | 〜から | てやんでえ（老、戏剧化） | 现代已淡 |
| 北海道 | 私、俺 | 〜だべ、〜っしょ | 〜ない | 〜から | なまら（很）、したっけ | 接近标准语 |
| 东北 | おら（老）、俺 | 〜だ、〜だべ | 〜ね、〜ねえ | 〜がら | んだ（对） | 差别大，津轻、秋田等全国播出会上字幕；写一点就够 |
| 名古屋 | 俺、わし | 〜だがや、〜だで | 〜せん、〜ん | 〜で | でら（很）、〜みゃあ（老、刻板） | |
| 広島 | わし、うち | 〜じゃ、〜じゃけえ | 〜ん | 〜けえ | ぶち（很）、〜とる | 黑帮片（仁侠）味重，别写成都是黑帮 |
| 博多、福冈 | 俺、うち | 〜ばい、〜たい | 〜ん | 〜けん | 〜と（说明；疑问 〜と？，如なんしようと？） | 女性「〜と？」有人气 |
| 鹿儿岛 | おい、おいどん（刻板） | 〜ど、〜じゃ | 〜ん | 〜で | | 真方言外人听不懂，通常用很轻的 |
| 冲绳 | わん（琉球语）、私 | 〜さー、〜よー | 〜ない | 〜から | なんくるないさ、はいさい | 琉球语和冲绳口音是两回事；当心观光刻板 |

**声调问题同样存在**：这些地方的声调 TTS 也念不出来，处理办法同第七节。
